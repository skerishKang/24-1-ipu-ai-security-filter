# Prompts

보안 치환 워크벤치에서 사용할 템플릿과 프롬프트 자산을 관리한다.

예상 범위:

- 수동 모드 복사용 프롬프트 템플릿
- 자동 모드 전달 전 안전 가이드
- 보안 점검용 시스템 메시지 초안

현재는 문서 우선 단계이므로 실제 프롬프트 구현은 후속 작업으로 둔다.

현재 추가된 운영용 프롬프트:

- `codex-verification-prompt.md`
  - WSL/Codex 기준 검증 프롬프트
- `minimax-browser-verification-prompt.md`
  - Windows 브라우저 검증 프롬프트
