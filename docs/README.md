## 문서 운영 원칙

- 상위 방향은 `docs/00-master-roadmap.md`에서 관리한다.
- 사업 문서는 `docs/business`에 누적한다.
- 개발 문서는 `docs/development`에 누적한다.
- 새로운 문서가 생기면 필요한 경우 각 인덱스에만 링크를 추가한다.

## 결론

`docs/`는 상세 내용을 모두 담는 곳이 아니라, 어디서부터 읽고 어떤 문서로 들어가야 하는지 안내하는 허브다.  
상위 로드맵, 사업 인덱스, 개발 인덱스를 중심으로 문서 흐름을 유지하면 된다.
