# 38. Sample-003 Source Investigation Note

## 목적

이 문서는 `meeting-audio-sample-003` 에 넣을 실제 3명 이상 회의성 자산을 어디서 찾을지 조사 방향을 정리한다.

## 대상 샘플

- 메타:
  - [`samples/meeting-audio-sample-003.yaml`](./samples/meeting-audio-sample-003.yaml)
- 관련 TODO:
  - [`34-sample-003-asset-acquisition-todo.md`](./34-sample-003-asset-acquisition-todo.md)

## 현재 결론

지금 단계에서는 실제 자산이 아직 없으므로, 먼저 후보 소스 범주를 좁히는 것이 맞다.  
우선순위는 "공개 사용 가능", "3명 이상 발화가 분명", "90초~180초 발췌 가능", "온라인 회의형 압축 음성에 가까움" 순이다.

## 우선 조사 범주

### 1. 공개 패널 토크 / 라운드테이블 클립

- 장점:
  - 3명 이상 발화 구조가 비교적 명확하다
  - 회의형 또는 토론형 발화 흐름을 보기 좋다
- 조건:
  - 진행자 포함 3명 이상이 실제로 말하는 구간
  - 음악/자막 효과가 과하지 않은 구간

현재 판단:
- 가장 현실적인 1순위 후보

### 2. 공개 세미나 Q&A / 좌담회 발췌

- 장점:
  - 다화자 구조와 발화 교대를 확보하기 쉽다
- 단점:
  - 현장 잡음, 박수, 마이크 편차가 심할 수 있다

현재 판단:
- 2순위 후보

### 3. 실제 온라인 회의 녹화 발췌

- 장점:
  - `online_meeting_compressed` 환경과 가장 가깝다
- 단점:
  - 권한과 개인정보 이슈가 크다

현재 판단:
- 공개/익명화 기준이 명확할 때만 고려
- 현재는 공개 자산보다 후순위

## 후보 소스 체크 기준

- `3명 이상` 발화가 분명한가
- `90초 ~ 180초` 발췌가 가능한가
- 한국어 위주인가
- 온라인 회의형 압축 음성이나 그에 가까운 환경인가
- 과도한 잡음과 음악이 없는가
- 공개 사용 또는 익명화 가능 여부가 명확한가

## 확보 후 바로 할 일

1. 발췌 구간 확보
2. [`meeting-audio-sample-003.yaml`](./samples/meeting-audio-sample-003.yaml) `storage_path` 갱신
3. Whisper 1회 관찰
4. `meeting-audio-sample-003.observation.md` 작성

## 현재 결론

sample-003는 실제 회의 원본보다 공개 패널 토크나 세미나 Q&A 발췌에서 먼저 찾는 것이 현실적이다.  
현재 기준으로는 `3명 이상`, `90초~180초`, `온라인 회의형에 가까운 압축 음성` 조건을 만족하는 공개 클립을 찾는 것이 가장 합리적이다.
