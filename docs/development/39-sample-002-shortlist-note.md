# 39. Sample-002 Shortlist Note

## 목적

이 문서는 `meeting-audio-sample-002` 실제 자산 확보를 위해 1차로 볼 후보 유형을 더 좁혀 정리한다.

## 현재 결론

sample-002는 후보 소스 범주까지는 정리됐고, 이제는 "어떤 형태의 2명 대화 클립을 먼저 찾을 것인가"를 좁히는 단계다.

## 1차 shortlist

### 1. 진행자 + 출연자 공개 인터뷰 짧은 구간

- 이유:
  - 2명 대화 구조가 가장 분명하다
  - 화자 교대가 비교적 읽기 쉽다
  - 길이 `20초 ~ 40초` 발췌가 쉽다

현재 판단:
- `최우선`

### 2. 2인 팟캐스트 / 토크 클립

- 이유:
  - 대화 자료는 많다
  - 2명 발화 구조 확보 가능성도 높다
- 주의:
  - 배경음과 웃음, 겹침 발화가 많으면 첫 샘플로는 부적합

현재 판단:
- `차선`

### 3. 공개 업무형 대담 / 인터뷰성 브이로그 대화 구간

- 이유:
  - 업무 대화 느낌을 반영하기 좋다
- 주의:
  - 실제 업무 대화처럼 보여도 권한/개인정보 기준을 먼저 확인해야 한다

현재 판단:
- `후순위`

## 제외 우선순위

아래는 첫 sample-002 후보로는 피한다.

- 배경음악이 강한 클립
- 3명 이상이 실제로 섞이는 클립
- 한 사람이 길게 말하는 독백형 클립
- 너무 짧아서 화자 교대가 안 드러나는 클립
- 너무 길어서 발췌 기준이 애매한 클립

## 선택 기준 요약

1. 2명 대화가 분명한가
2. 한국어 위주인가
3. `20초 ~ 40초` 발췌가 쉬운가
4. 화자 교대가 읽히는가
5. 권한/공개 사용 기준이 명확한가

## 현재 결론

sample-002는 우선 `진행자 + 출연자` 구조의 공개 인터뷰 짧은 구간부터 찾는 것이 가장 효율적이다.  
그다음이 2인 팟캐스트/토크 클립이다.
