# 01. Product Overview

## 제품 한 줄 정의

IPU AI Security Filter는 민감정보를 내부에서 먼저 보호한 뒤 외부 AI를 사용할 수 있도록 돕는 기업용 AI 보안필터다.

## 문제 정의

기업은 외부 AI의 높은 성능을 원하지만 다음과 같은 이유로 실제 도입에 제약을 받는다.

- 원문 데이터가 외부 API로 직접 전송될 수 있다.
- 임직원이 민감정보 포함 텍스트를 무심코 복붙할 수 있다.
- 누가 어떤 정보를 어떤 방식으로 치환했는지 추적이 어렵다.
- 보안팀과 현업팀이 동시에 납득할 수 있는 운영 방식이 부족하다.

## 제품 접근 방식

IPU는 외부 AI를 대체하는 것이 아니라, 외부 AI 앞단에 위치하는 보안 계층을 제공한다.

1. 사용자가 텍스트, 문서, 음성 데이터를 입력한다.
2. 내부 보안 엔진이 민감정보를 탐지한다.
3. 세션별 동적 치환을 수행한다.
4. 초기에는 치환 결과와 리포트를 보여준다.
5. 이후 필요 시 외부 모델 API 전송과 응답 역치환을 자동화한다.

## 초기 MVP 포지셔닝

- 초기 MVP는 "보안 치환 워크벤치"다.
- 핵심은 AI 자동화보다 보안 처리의 가시성과 검토 가능성이다.
- 사용자는 원문, 치환본, 탐지 리포트를 비교하며 안전한 프롬프트를 만든다.

## 주요 사용자

- 외부 AI를 업무에 도입하려는 기업
- 보안팀 또는 컴플라이언스 담당자
- 사내 문서, 고객 데이터, 계약 정보, 재무 데이터를 다루는 실무자

## 제공 가치

- 외부 AI 활용 전 민감정보 노출 위험을 줄인다.
- 치환 전후 흐름을 분리해 운영 설명 가능성을 높인다.
- 자동 호출 없이도 수동 모드만으로 즉시 실무 가치를 제공한다.
- 이후 자동 모드로 자연스럽게 확장할 수 있다.
