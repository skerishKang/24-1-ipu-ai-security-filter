# IPU AI 보안필터 Priority Filter

## 목적

이 문서는 `IPU AI 보안필터`에서 새로운 기능 아이디어, 고객 요청, 문서 작업, 파트너 제안이 들어왔을 때 우선순위를 빠르게 판단하기 위한 내부 필터다.  
목표는 “할 수 있는 일”과 “지금 해야 할 일”을 구분하는 것이다.

## 기본 원칙

- 좋은 아이디어가 많다고 다 지금 할 필요는 없다.
- 초기 단계일수록 우선순위 필터가 더 중요하다.
- 기능 수보다 제품 방향과 고객 검증이 우선이다.
- 우선순위는 흥미가 아니라 현재 단계 기준으로 판단한다.

## 가장 먼저 볼 질문

아래 질문에 먼저 답한다.

1. 이 일이 초기 고객 검증에 직접 도움이 되는가
2. 이 일이 PoC 성공 가능성을 높이는가
3. 이 일이 제품 설명을 더 쉽게 만드는가
4. 이 일이 현재 제품 포지션과 맞는가
5. 이 일이 지금 단계에 비해 너무 무거운가

## 우선순위 판단 기준

## 1. 최고 우선순위

다음에 해당하면 지금 해야 할 가능성이 높다.

- 수동 모드 MVP를 더 안정적으로 만드는 일
- 데모 품질을 높이는 일
- PoC 제안과 실행에 직접 필요한 일
- 초기 고객 반응을 더 빨리 확인할 수 있는 일
- 반복적으로 나오는 고객 질문에 답하는 일

예시:

- 텍스트/파일 preview 안정화
- 데모 스크립트 정리
- 타깃 계정 정리
- PoC 제안서 템플릿 작성

## 2. 중간 우선순위

필요는 있지만 지금 당장 첫 번째는 아닌 일이다.

- 입력 형식 확대
- 정책 분기 고도화
- 운영 관찰성 보강
- 내부 보고 문서 체계화

예시:

- PDF/DOCX 지원 검토
- policy 차별화 심화
- 로그 구조 고도화
- KPI 대시보드 정리

## 3. 낮은 우선순위

언젠가는 의미가 있을 수 있지만, 지금 하면 집중을 깨는 일이다.

- 범용 소비자용 기능
- 화려한 관리자 콘솔
- 지나치게 큰 자동화
- 모든 산업군용 확장
- 브랜딩만을 위한 작업

예시:

- 대규모 사용자 관리
- 복잡한 디자인 개편
- 너무 이른 마케팅 채널 확장

## 빠른 필터링 규칙

### 바로 한다

- PoC와 데모에 직접 필요한 일
- 고객이 반복적으로 요청하는 핵심 기능
- 현재 막혀 있는 명확한 병목

### 잠깐 미룬다

- 중요하지만 지금 PoC 가치와 직접 연결되지 않는 일
- 나중에 해야 하지만 지금은 리소스 대비 효과가 약한 일

### 지금 안 한다

- 기능은 흥미롭지만 제품 방향을 흐리는 일
- 설명을 더 어렵게 만드는 일
- 특정 한 고객만을 위한 예외적 요구

## 실전 판단 예시

### 예시 1: .txt 파일 업로드 지원

- PoC 직접 도움: 높음
- 데모 품질 향상: 높음
- 구현 부담: 중간
- 판단: 지금 한다

### 예시 2: PDF, DOCX, HWP를 한 번에 전부 지원

- PoC 직접 도움: 중간
- 구현 부담: 높음
- 범위 확대 위험: 높음
- 판단: 단계적으로 미룬다

### 예시 3: fancy 대시보드 UI

- PoC 직접 도움: 낮음
- 설명 개선: 낮음
- 구현 부담: 중간
- 판단: 지금 안 한다

### 예시 4: 고객 인터뷰 정리 문서

- PoC 직접 도움: 높음
- 고객 검증: 높음
- 구현 부담: 낮음
- 판단: 바로 한다

## 내부 우선순위 판단 문장

새 요청이 들어오면 아래 문장으로 먼저 정리한다.

- 이건 지금 당장 PoC를 더 잘하게 만드는가
- 이건 지금 고객에게 더 잘 설명하게 만드는가
- 이건 지금 제품 가치를 더 선명하게 만드는가
- 아니면 그냥 하고 싶은 일인가

## 우선순위가 흔들릴 때 보는 기준

- 현재 가장 강한 고객 Pain Point는 무엇인가
- 지금 보여줄 수 있는 데모는 무엇인가
- 다음 30일 목표는 무엇인가
- 이 작업이 그 목표와 직접 연결되는가

## 우선순위 판단 후 남겨야 할 것

- 판단 결과: 지금 한다 / 미룬다 / 안 한다
- 이유
- 다시 볼 시점

이 내용은 decision log, monthly review, backlog 중 하나에 짧게 남기면 된다.

## 결론

좋은 priority filter는 아이디어를 막는 문서가 아니라, `지금 가장 중요한 것에 집중하게 만드는 문서`다.  
IPU AI 보안필터는 초기 단계이므로, 기술 확장보다 PoC 가능성과 고객 검증에 직접 연결되는 일을 우선해야 한다.
