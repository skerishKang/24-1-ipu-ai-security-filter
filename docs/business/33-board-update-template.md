# IPU AI 방화벽 Board Update Template

## 목적

이 문서는 월간 또는 분기 단위로 내부 의사결정자, 초기 투자자, 운영사, 핵심 파트너에게 진행 상황을 공유할 때 사용할 템플릿이다.  
목표는 단순한 작업 나열이 아니라, 현재 어디까지 왔고 무엇이 잘되고 있으며 무엇이 남아 있는지를 빠르게 이해시키는 것이다.

## 사용 원칙

- 길게 쓰기보다 핵심만 적는다.
- 사실, 변화, 리스크, 다음 액션 순서로 정리한다.
- 좋은 점뿐 아니라 리스크도 같이 적는다.
- 기술 진행과 사업 진행을 함께 본다.

## 문서 제목 예시

- `IPU AI 방화벽 Monthly Update - YYYY.MM`
- `IPU AI 방화벽 Board Update - QX YYYY`

## 1. 한 줄 요약

이번 기간의 핵심 진전 한 문장.

예시:

- 수동 모드 MVP의 기본 흐름과 문서 체계를 정리했고, 초기 PoC 준비가 가능한 수준까지 골격을 만들었다.
- 텍스트 및 `.txt` 기반 manual-preview 흐름을 연결했고, 초기 고객 논의를 시작할 준비가 되었다.

## 2. 이번 기간 주요 진전

### 제품/기술

- 프론트엔드 워크벤치 진행 상황
- 백엔드 API 진행 상황
- 엔진 탐지/치환/복원 진행 상황
- 테스트/검증 상태

### 사업/문서

- 포지셔닝 문서
- 세일즈 자료
- PoC 템플릿
- 타깃 계정/아웃리치 준비

## 3. 지금 상태 요약

### 현재 가능한 것

- 예: 텍스트 manual-preview
- 예: `.txt` 파일 업로드 preview
- 예: 수동 모드 시연

### 아직 안 되는 것

- 예: 자동 모드
- 예: PDF/DOCX/HWP 입력
- 예: 관리자 콘솔
- 예: 온프레미스 패키징

## 4. 시장/고객 관점 업데이트

- 고객 인터뷰 진행 여부
- 타깃 계정 발굴 현황
- 잠재 PoC 대상
- 시장 반응 또는 가설 변화

## 5. 핵심 리스크

### 기술 리스크

- 탐지 품질
- 치환/복원 안정성
- 입력 확장 난이도

### 사업 리스크

- 초기 고객 확보
- 긴 세일즈 사이클
- 제품 메시지 혼선 가능성

## 6. 이번 기간 배운 점

- 무엇이 예상보다 잘 맞았는가
- 무엇이 예상보다 어려웠는가
- 어떤 가설을 수정했는가

## 7. 다음 기간 우선순위

### 제품/기술

- 예: 파일 입력 확장
- 예: 자동 모드 일부 검토
- 예: 정책 분기 고도화

### 사업

- 예: 타깃 계정 정리
- 예: 아웃리치 시작
- 예: PoC 제안서 발송

## 8. 지원이 필요한 부분

- 고객 소개
- 보안/금융권 네트워크 연결
- 파트너사 연결
- 피드백이 필요한 자료

## 9. 간단한 KPI 예시

- 타깃 계정 수
- 인터뷰 수
- 데모 수
- PoC 논의 수
- 개발 마일스톤 달성 수

## 10. 마무리 문구 예시

- 현재는 제품과 시장 포지션의 기본 골격을 빠르게 정리하는 단계이며, 다음 기간에는 실제 고객 검증과 PoC 진입에 더 집중할 예정이다.
- 기술 골격은 정리되고 있고, 이제 중요한 것은 실제 고객 문제에 맞춰 좁은 범위의 검증을 시작하는 것이다.

## 짧은 샘플 형식

### 한 줄 요약

수동 모드 MVP와 사업 문서 체계를 정리했고, 초기 고객 PoC를 논의할 준비를 마쳤다.

### 주요 진전

- manual-preview API 구축
- 엔진 세션 TTL 반영
- `.txt` 파일 preview 지원
- 사업 문서 세트 정리

### 리스크

- 아직 자동 모드 없음
- 문맥 유지형 치환 품질은 고도화 필요
- 초기 고객 검증 전 단계

### 다음 우선순위

- 파일 업로드 UI 연결
- 타깃 계정 정리
- 첫 아웃리치 및 데모 진행

## 결론

좋은 board update는 “우리가 얼마나 바빴는가”를 보여주는 문서가 아니라, `우리가 어디까지 왔고, 무엇이 리스크이며, 다음에 무엇을 할 것인가`를 빠르게 이해시키는 문서다.  
IPU AI 방화벽은 기술과 사업이 같이 움직여야 하므로, 두 축을 함께 업데이트하는 형식이 중요하다.
