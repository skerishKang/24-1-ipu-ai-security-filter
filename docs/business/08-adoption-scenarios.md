# IPU AI 보안필터 도입 시나리오

## 1. 문서 목적

이 문서는 `IPU AI 보안필터`를 실제 조직이 어떤 순서로 도입할 수 있는지 시나리오 중심으로 설명하기 위한 문서다.

목적은 세 가지다.

- 고객이 실제 사용 장면을 상상할 수 있게 한다
- 영업/제안 시 구체적인 파일럿 제안을 가능하게 한다
- 제품 로드맵과 고객 도입 흐름을 연결한다

## 2. 기본 도입 원칙

IPU는 전사 일괄 도입보다 단계적 도입이 더 적합하다.

권장 순서는 다음과 같다.

1. 특정 부서 한정
2. 특정 데이터 유형 한정
3. 수동 모드 우선 검증
4. 자동 모드 점진 확장

## 3. 시나리오 A. 대기업 법무팀 PoC

### 상황

법무팀은 계약서 초안 검토, 조항 비교, 요약, 리스크 정리를 위해 생성형 AI를 쓰고 싶다.

하지만 계약 상대방 이름, 금액, 일정, 담당자 이름을 외부 AI에 그대로 넣는 것은 부담스럽다.

### IPU 도입 방식

1. 법무팀 실무자가 계약서 초안 일부를 업로드한다.
2. IPU가 회사명, 금액, 담당자명 등을 치환한다.
3. 실무자는 치환본을 검토한다.
4. 수동 모드로 외부 AI에 붙여넣어 요약과 질의응답을 수행한다.
5. 결과를 내부 검토 문서로 활용한다.

### 기대 효과

- 외부 AI 활용 금지 대신 통제된 활용 가능
- 법무팀 실무 효율 상승
- 이후 자동 모드 검토 명분 확보

## 4. 시나리오 B. 금융권 내부 문서 분석 지원

### 상황

금융권 조직은 내부 보고서, 상담 스크립트, 상품 설명자료를 생성형 AI로 정리하고 싶다.

하지만 고객정보, 계좌 관련 정보, 금액 정보, 내부 심사 용어 노출을 우려한다.

### IPU 도입 방식

1. 특정 업무 문서에 한정해 시범 적용
2. 고객정보와 수치 항목을 보호형 치환
3. 외부 AI를 활용한 초안 생성
4. 내부 검토 후 사용

### 기대 효과

- 로컬 LLM 전면 도입 전의 현실적 대안
- 외부 SOTA 모델 품질 확보
- 보안 승인 가능 구조 제시

## 5. 시나리오 C. 공공기관 보고서 요약 파일럿

### 상황

공공기관은 보고자료, 회의자료, 정책 초안을 빠르게 요약하거나 정리할 필요가 있다.

하지만 내부 행정 정보와 기관 고유 문구를 외부 AI에 직접 넣는 것은 부담스럽다.

### IPU 도입 방식

1. 특정 문서 유형만 대상으로 파일럿
2. 문서 업로드 후 민감정보 보호형 치환 수행
3. 수동 모드 기준으로 외부 AI 활용
4. 활용 결과를 내부 검토

### 기대 효과

- 생성형 AI 도입에 대한 심리적 장벽 감소
- 전면 로컬 구축 전의 중간 단계 확보
- 시범사업 보고서 작성에 유리

## 6. 시나리오 D. 컨설팅 조직의 고객 문서 분석

### 상황

컨설팅 또는 회계 조직은 고객사명, 담당자명, 금액, 프로젝트명을 포함한 문서를 자주 다룬다.

생성형 AI로 정리하고 싶지만 고객 신뢰 문제가 있다.

### IPU 도입 방식

1. 고객사 실명과 프로젝트명을 보호형 치환
2. 외부 AI를 활용한 요약/정리 초안 생성
3. 최종 문서는 내부에서 검토 후 복원

### 기대 효과

- 고객정보 보호 명분 강화
- 고품질 외부 모델 활용 유지
- 반복 문서 업무 효율화

## 7. 단계별 도입 전략

## 7-1. 1단계: 수동 모드 PoC

### 목적

- 제품 신뢰 확보
- 치환 품질 검증
- 보안팀 검토 가능성 확보

### 형태

- 특정 부서
- 특정 문서 유형
- 사용자 수 제한

## 7-2. 2단계: 반자동 운영

### 목적

- 실사용 빈도 증가
- 운영 프로세스 정착

### 형태

- 치환과 리포트는 자동
- 외부 AI 입력은 사용자 확인 후 진행

## 7-3. 3단계: 자동 모드 확장

### 목적

- 사용 편의성 향상
- 조직 단위 확장

### 형태

- 서버가 외부 AI 호출 수행
- 응답 역복원 자동화
- 정책과 감사 기능 강화

## 8. 도입 시 영업 포인트

각 시나리오에서 공통적으로 강조할 메시지는 다음과 같다.

- 외부 AI를 막는 대신 안전하게 허용할 수 있다
- 고성능 모델을 포기하지 않아도 된다
- 전면 로컬 구축보다 가볍게 시작할 수 있다
- 수동 모드부터 시작하므로 위험 부담이 낮다

## 9. 한 줄 결론

IPU AI 보안필터는 전사 대규모 도입보다, 특정 부서와 특정 문서 흐름에서 수동 모드 PoC로 시작해 점진적으로 자동 모드와 엔터프라이즈 기능으로 확장하는 방식이 가장 현실적이다.
