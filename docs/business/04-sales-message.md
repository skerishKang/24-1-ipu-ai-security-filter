# IPU AI 보안필터 세일즈 메시지

## 1. 서비스 한 줄 소개

IPU AI 보안필터는 민감정보를 내부에서 보호·변환한 뒤, GPT, Claude, Gemini 같은 외부 SOTA AI를 안전하게 사용할 수 있게 해주는 기업용 AI 보안 서비스다.

## 2. 아주 짧은 설명

기밀은 내부에 두고, AI 성능은 외부 최고 모델을 그대로 쓰게 해주는 서비스다.

## 3. 고객 문제 중심 설명

많은 조직은 생성형 AI를 쓰고 싶지만, 내부 정보가 외부 모델로 직접 나가는 것이 불안해 도입을 주저한다.

그 결과 두 가지 비효율이 생긴다.

- 외부 AI를 금지해 생산성을 포기한다.
- 비싼 GPU 서버를 사서 성능이 아쉬운 로컬 모델을 운영한다.

IPU AI 보안필터는 이 문제를 해결한다.

## 4. 대표 세일즈 문구

### 문구 A

외부 AI를 막지 마십시오. 내부 데이터를 보호한 상태로 쓰게 하십시오.

### 문구 B

비싼 GPU 서버를 추가 구매하지 않고도, 내부 정보는 보호하고 외부 최고 성능 AI는 그대로 활용할 수 있습니다.

### 문구 C

로컬 LLM 구축의 비용과 성능 한계를 감수하지 않고, 조직 보안 정책 안에서 SOTA AI를 사용할 수 있게 해주는 보호 계층입니다.

## 5. 고객 유형별 문구

### 대기업용

IPU AI 보안필터는 사내 기밀을 직접 외부 AI에 보내지 않고도, GPT와 Claude 같은 최고 성능 모델을 업무에 활용할 수 있게 해주는 AI 보안 필터다.

### 공공기관용

IPU AI 보안필터는 민감 행정정보를 직접 외부 생성형 AI에 노출하지 않고도, 문서 요약과 분석 업무에 생성형 AI를 단계적으로 도입할 수 있게 해주는 보호형 서비스다.

### 금융권용

IPU AI 보안필터는 고객정보와 내부 재무정보를 보호된 상태로 변환한 뒤 외부 AI를 활용할 수 있게 해주는 금융권 지향 AI 보안 필터다.

## 6. 비교 문구

### 기존 방식

- 외부 AI 금지
- 또는 전면 로컬 LLM 구축
- 또는 보안 우려를 감수한 채 외부 AI 직접 사용

### IPU 방식

- 입력 전 보호
- 외부 전송 전 변환
- 응답 후 복원
- 세션 종료 후 매핑 폐기

## 7. 내부 발표용 문장

우리는 로컬 LLM을 파는 회사가 아니라, 외부 최고 성능 AI를 보안 정책 안에서 사용할 수 있게 해주는 인프라를 만든다.

## 8. 제안서 표지용 문장

IPU AI 보안필터

민감정보는 내부에서 보호하고, 외부 SOTA AI는 안전하게 활용하는 기업용 AI 보안 서비스
