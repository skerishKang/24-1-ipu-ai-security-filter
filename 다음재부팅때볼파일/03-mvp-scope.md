# 03. MVP Scope

## MVP 목표

초기 MVP는 기업 사용자가 원문을 안전하게 치환하고, 그 결과를 검토 가능한 형태로 확인하는 웹 기반 보안 치환 워크벤치다.

## 포함 범위

### 반드시 포함

- 텍스트 입력 기반 치환 워크플로우
- 기본 파일 업로드 인터페이스
- 민감정보 탐지 결과 리포트
- 세션별 동적 치환 결과 생성
- 복사 가능한 외부 모델용 프롬프트 출력
- 수동 모드 중심의 워크벤치 UI

### 가능하면 포함

- 문서 파일 텍스트 추출의 최소 버전
- 음성 업로드 후 텍스트 변환 최소 연결
- 일반인/전문가 공통 음성 업로드
- 정책 템플릿 선택 UI

### 제외 범위

- 다수 외부 모델 자동 연동의 완성형 구현
- 관리자 콘솔과 조직 단위 권한 체계
- 장기 보관용 데이터 저장소
- 정교한 결재/감사 시스템
- 실시간 협업 기능

## 성공 조건

- 사용자가 브라우저에서 원문을 넣고 치환본을 바로 얻을 수 있다.
- 어떤 정보가 탐지됐는지 리포트로 확인할 수 있다.
- 치환본을 외부 AI에 붙여넣기 적합한 형태로 제공할 수 있다.
- 자동 모드 없이도 제품 가치가 설명 가능하다.

## 비기능 목표

- 구조가 명확해야 한다.
- 엔진과 웹 레이어의 경계가 분리돼야 한다.
- 자동 모드를 나중에 붙이기 쉽게 API와 서비스 계약이 보존돼야 한다.
- 추후 기업 정책 확장이 가능해야 한다.
